# Проверка каталога — 26.09.2026

Реализованы дерево категорий, поиск с путём до категории, множественный выбор,
счётчики потомков, скрытие пустых веток и сохранение выбранных пустых категорий.
Категории сопоставляются по внутреннему ID (для старых ссылок также по slug).
Составной ключ ThinkLink источник/уровень/внешний ID не менялся.

Счётчики категорий исключают выбранные категории из своего запроса, счётчики
брендов — выбранные бренды. Остальные фильтры применяются. Выбор внутри одного
фильтра работает как OR, между фильтрами — AND. Это позволяет добавлять
альтернативы. Диапазон цен исключает только ручные ограничения цены и никогда
не перезаписывает введённые границы. Корректная цена — конечное число больше 0.
В наличии — stock > 0; режим «Все» снимает ограничение по остатку.

URL хранит search, category, brand, min, max, stock, sort, limit, page.
Старые параметры q/minPrice/maxPrice также читаются. Изменение фильтров,
сортировки и размера страницы сбрасывает страницу. Запросы откладываются на
250 мс и отменяются при изменении состояния; отменённые ответы не применяются.
Мобильная панель хранит черновик до применения, Escape/закрытие его отменяет.

Проверено:
- npm run type-check — успешно.
- node scripts/test-catalog.cjs (при работающем localhost:3000) — успешно.
  Скрипт читает API без изменения базы: счётчики, родители, размеры страниц,
  сортировка, SKU, цены, пустые результаты, сохранение выбора, невалидный URL.
- npm run test:thinklink — успешно в выделенной stp_thinklink_test:
  импорт, три уровня с совпадающими внешними ID, наценка и конвертация,
  повторная синхронизация, заявка и серверная цена, остатки, ошибочный ответ.
- Браузер: настольный экран 1440×1000 и мобильный 390×844; поиск категории
  с путём через все три уровня; выбор листа (2 товара); reload и история;
  применение и сброс мобильного черновика; пустая выдача; переход на страницу 2
  и сброс на 1 при смене размера; поиск «Кабель питания» и очистка клавиатурой.
  Горизонтального переполнения на мобильном экране нет, кнопки панели видимы.
